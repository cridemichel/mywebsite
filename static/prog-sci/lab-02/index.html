if(Eigen3_FOUND)
1    target_link_libraries(basic_neural Eigen3::Eigen)
else()
    message(STATUS "Eigen non trovata: uso libs/eigen")
    target_include_directories(basic_neural PRIVATE libs/eigen)
endif()
target_link_libraries(basic_neural ${OpenCV_LIBS})
1
È la riga che quasi tutti dimenticano. Trovare Eigen con find_package non basta: senza questa, la compilazione muore con fatal error: Eigen/Dense: No such file or directory anche con Eigen installata.

Soluzione del Laboratorio 01: il main.cpp

main.cpp
#include <cstdlib>   // std::srand
#include <ctime>     // std::time
#include <iostream>
#include <Eigen/Dense>
#include <opencv2/opencv.hpp>

int main() {
1    // std::srand(std::time(nullptr));
    Eigen::MatrixXf W = Eigen::MatrixXf::Random(3, 4);
    Eigen::VectorXf x = Eigen::VectorXf::Random(4);

    Eigen::VectorXf z = W * x;
    std::cout << "z e' " << z.rows() << "x" << z.cols() << ":\n" << z << "\n\n";

2    Eigen::ArrayXf z_relu = z.array().max(0.0f);
    std::cout << "dopo la ReLU:\n" << z_relu << "\n\n";
    // ... segue l'immagine OpenCV
1
Random() usa std::rand(): senza un seme la sequenza è sempre la stessa. Togliendo il commento i numeri cambiano a ogni esecuzione.
2
Il vostro primo forward pass: un prodotto matrice-vettore e una non linearità. È tutto quello che fa uno strato.

I vostri numeri possono essere diversi da questi, perché std::rand() cambia da un sistema all’altro, ma a ogni esecuzione saranno gli stessi finché non date un seme con std::srand. La forma invece no: z deve essere \(3 \times 1\), e dopo la ReLU i negativi devono essere esattamente 0 e i positivi invariati. Se le dimensioni non tornano, avete invertito W e x.

Obiettivo di Oggi

Iniziare la costruzione del framework BASIC_NEURAL++ partendo dalle basi assolute. Non scriveremo ancora codice neurale, ma prepareremo il terreno.

L’ambiente di lavoro è fondamentale: un ingegnere del software deve conoscere e controllare perfettamente i propri strumenti (compilatore, IDE, build system).

Task 1: Il Compilatore

Il compilatore l’avete già installato nel Laboratorio 01: qui si tratta solo di verificare che risponda.

g++ --version      # Linux e WSL
clang++ --version  # macOS (lì anche g++ è il clang di Apple)
cmake --version

Se uno di questi comandi non risponde, tornate alle slide del Laboratorio 01: lì ci sono le istruzioni per Linux, macOS e Windows (WSL 2).

Task 2: CMake e IDE

Useremo CMake per gestire la compilazione multi-file del nostro framework, e un IDE per scrivere il codice.

  1. Apri il tuo IDE preferito (VS Code, CLion, ecc.)
  2. Apri la cartella del progetto del Laboratorio 01, basic_neural_plusplus (quella con CMakeLists.txt e main.cpp): da qui in avanti è il progetto del framework.

Task 3: Hello World con CMake

  1. Riusate il CMakeLists.txt del Laboratorio 01, quello con Eigen e OpenCV. Non serve rifarlo: da qui in avanti quel file cresce, non si riscrive.
  2. Sostituite il main.cpp con uno che stampi a schermo “Inizio progetto BASIC_NEURAL++!”.
  3. Compilate ed eseguite con cmake -B build && cmake --build build && ./build/basic_neural (o col pulsante Build del vostro IDE).

(Per un “hello world” Eigen e OpenCV non servirebbero, ma tenere un solo file di build evita di ritrovarsi con due progetti diversi.)

Task 4: Esplorazione Tipi Base

Nel tuo main.cpp, prova a dichiarare, stampare e combinare alcune variabili fondamentali per il Machine Learning:

  • Un int (es. numero di epoche)
  • Un double (es. learning rate o peso)
  • Prova a moltiplicarli e stamparli. Cosa succede se dividi un int per un altro int (es. 5 / 2)? E se ne casti uno a double?
