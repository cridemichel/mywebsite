Task 3: il quesito 1 al calcolatore

Il quesito 1 della Lezione 03: loss \(E(x) = x^2\), partenza \(x_0 = 1\), passo \(x \leftarrow x - \eta\,E'(x)\) con \(E'(x) = 2x\). Per quali \(\eta\) il metodo converge, e quale centra il minimo in un solo passo?

  1. Scrivete un ciclo for che faccia cinque passi e stampi \(x\) dopo ognuno.
  2. Mettetelo dentro un secondo ciclo che provi \(\eta = 0{,}25,\ 0{,}5,\ 0{,}75,\ 1,\ 1{,}25\):
for (int k = 1; k <= 5; ++k) {
    double eta = 0.25 * k;
    // ... i cinque passi
}
  1. Per ogni \(\eta\): la discesa converge, centra il minimo, oscilla o diverge? Confrontate con la risposta del quesito.

Il contatore è un int e \(\eta\) si ricava da lui: un ciclo for (double eta = 0.1; ...; eta += 0.1) accumulerebbe errori di arrotondamento, perché \(0{,}1\) non è rappresentabile esattamente in binario.

Task 4: la catena di due neuroni

L’esercizio in classe della Lezione 03: due neuroni sigmoidi in fila, senza bias.

\[ x \;\to\; z_1 = w_1 x \;\to\; a_1 = \sigma(z_1) \;\to\; z_2 = w_2 a_1 \;\to\; a_2 = \sigma(z_2), \qquad E = (a_2 - y)^2 \]

con \(\sigma(z) = 1/(1 + e^{-z})\) e \(\sigma'(z) = \sigma(z)\,\big(1 - \sigma(z)\big)\). La backpropagation dà

\[ \delta_2 = 2(a_2 - y)\,\sigma'(z_2), \quad \delta_1 = w_2\,\delta_2\,\sigma'(z_1), \quad \frac{\partial E}{\partial w_2} = \delta_2\, a_1, \quad \frac{\partial E}{\partial w_1} = \delta_1\, x . \]

Con \(x = 1\), \(w_1 = w_2 = 1\), \(y = 1\) dovete ritrovare \(E = 0{,}1056\) e \(\partial E/\partial w_1 = -0{,}0280\).

Task 4: in C++

Con \(x = 1\), \(w_1 = w_2 = 1\), \(y = 1\):

  1. Forward: una variabile double per ciascuna di \(z_1, a_1, z_2, a_2\) ed \(E\). La sigmoide è 1.0 / (1.0 + std::exp(-z)), con #include <cmath>.
  2. Backward: \(\sigma'(z) = a\,(1-a)\), poi \(\delta_2\), \(\delta_1\), \(\partial E/\partial w_2 = \delta_2\, a_1\) e \(\partial E/\partial w_1 = \delta_1\, x\).
  3. Stampate una tabella (una riga per grandezza, una colonna per strato, colonne separate da "\t") e confrontatela con la soluzione nella Lezione 03.
  4. Gradient check: ricalcolate \(E\) con \(w_1 + h\) e con \(w_1 - h\), \(h = 0{,}01\), e confrontate \(\big[E(w_1+h) - E(w_1-h)\big]/2h\) con \(\partial E/\partial w_1\).

Il forward va ricopiato due volte: è scomodo, ed è voluto. Nel Laboratorio 03 lo risolveremo con una funzione, double sigmoid(double z).

Task 5: addestrare la catena

Ora i pesi si aggiornano: discesa del gradiente su \(w_1\) e \(w_2\), con un solo esempio e \(\eta = 1\):

for (int t = 0; t <= 200; ++t) {
    // forward (a1, a2, E) e backward (delta2, delta1), con i pesi attuali
    if (t % 20 == 0) { /* stampa t, E, w1 e w2 */ }
    w1 = w1 - eta * dE_dw1;
    w2 = w2 - eta * dE_dw2;
}

I due gradienti vanno calcolati entrambi prima di aggiornare i pesi, nello stesso punto (Lezione 03): aggiornare w2 e poi calcolare delta1 con il w2 nuovo è un errore silenzioso. A \(t = 0\) deve uscire \(E = 0{,}1056\), come nel Task 4.

  1. \(E\) scende? Di quanto, in 200 passi?
  2. Guardate i pesi: si fermano?
  3. Rifate tutto con \(y = 0{,}8\). Cosa cambia, e perché? Un suggerimento: per quale \(z\) la sigmoide vale 1?
