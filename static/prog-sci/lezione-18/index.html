La libreria standard

La libreria standard del C++ contiene, fra l’altro, strutture dati e algoritmi già scritti, tutti template (Lezione 16): si usano con il tipo che serve, come std::vector<double> o std::vector<Layer*>. Questa parte si chiama spesso STL (Standard Template Library), dal nome della libreria da cui è nata. Ha tre componenti:

  1. i contenitori, che tengono gli elementi: std::vector (Lezione 12) e, oggi, std::map;
  2. gli iteratori, oggetti che indicano un elemento di un contenitore e passano al successivo: servono a scorrere un contenitore senza sapere come è fatto dentro;
  3. gli algoritmi, funzioni template di <algorithm> come std::sort (Lezione 16), che lavorano su un intervallo di elementi indicato da due iteratori.

Ripasso: std::vector

Dalla Lezione 12, std::vector<T> (da <vector>) è un array nell’heap, di dimensione variabile, che gestisce da sé la sua memoria (RAII, Lezione 09): push_back aggiunge un elemento in fondo, size() dà il numero di elementi, v[i] è l’elemento i, e for (double x : v) scorre gli elementi.

Un vettore si può anche creare già pieno, con i valori fra graffe:

std::vector<int> w = {28, 30, 24};    // un vettore con tre elementi

Oggi aggiungiamo:

  • che cosa succede con un indice fuori dal vettore, e il metodo at();
  • come cresce la memoria del vettore: capacity() e reserve();
  • perché gli elementi contigui contano, e perché un vettore di vettori non li ha.

L’indice fuori dal vettore: [] e at()

indici.cpp
#include <iostream>
#include <stdexcept>
#include <vector>

int main() {
    std::vector<int> v = {28, 30, 24};
    try {
        std::cout << v.at(5) << "\n";
    } catch (const std::out_of_range& e) {
        std::cout << "Errore: " << e.what() << "\n";
    }
    std::cout << v[5] << "\n";
    return 0;
}
  • Riga 8: at(5) controlla l’indice, e se è fuori lancia un’eccezione std::out_of_range (Lezione 10), che il catch riceve: Errore: vector::_M_range_check: __n (which is 5) >= this->size() (which is 3).
  • Riga 12: come nella Lezione 12, [] non controlla l’indice e legge dopo la fine del vettore: l’AddressSanitizer si ferma con heap-buffer-overflow.

Provate: [] e at()

  1. In indici.cpp, alla riga 8, scrivete v.at(2) al posto di v.at(5). Cosa stampa?
    24, l’ultimo elemento, senza eccezioni: gli indici vanno da 0 a size() - 1. Poi la riga 12 ferma l’AddressSanitizer come prima.
  2. Ora scrivete v.at(3). Cosa succede?
    at() lancia l’eccezione, e il messaggio finisce con __n (which is 3) >= this->size() (which is 3): con tre elementi l’indice 3 è già fuori.

Regola pratica. [] quando l’indice lo controllate voi, per esempio in un ciclo da 0 a size(); at() quando l’indice arriva da fuori: un file, la riga di comando, chi usa il programma.

size() e capacity()

capacita.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<double> v;
    for (int i = 0; i < 10; i++) {
        std::cout << v.size() << "/"
                  << v.capacity() << " ";
        v.push_back(0.1 * i);
    }
    std::cout << "\n";
    return 0;
}
  • size(): quanti elementi ci sono nel vettore.
  • capacity(): per quanti elementi c’è già posto nella memoria allocata.

Output, uguale con g++ e con clang: 0/0 1/1 2/2 3/4 4/4 5/8 6/8 7/8 8/8 9/16.

Quando il posto finisce, push_back alloca un blocco più grande, ci copia gli elementi e libera quello vecchio. Con g++ e con clang il blocco nuovo ha il doppio dei posti: da 0 si passa a 1, poi a 2, 4, 8, 16 (in 1/1 e 2/2 il vettore è pieno). Le riallocazioni diventano sempre più rare, e in media una push_back richiede un tempo che non cresce con il numero degli elementi. Se il numero si conosce prima, v.reserve(n) alloca subito il posto per n elementi, e non si rialloca più.

Provate: reserve

  1. In capacita.cpp, dopo la riga 5, scrivete v.reserve(10);. Cosa stampa?
    0/10 1/10 2/10 … 9/10: il posto per 10 elementi c’è dall’inizio, e il vettore non rialloca mai.
  2. Cambiate v.reserve(10); in v.reserve(4);. Cosa stampa?
    0/4 1/4 2/4 3/4 4/4 5/8 6/8 7/8 8/8 9/16: finiti i 4 posti, il vettore raddoppia come prima.
  3. Togliete v.reserve(4);. Dopo la riga 5 scrivete v.push_back(1.0); e double& primo = v[0];, e prima di return 0; scrivete std::cout << primo << "\n";. Cosa succede?
    L’AddressSanitizer si ferma con heap-use-after-free: primo è una reference al primo elemento nel primo blocco, che le push_back del ciclo hanno sostituito e liberato. Dopo una riallocazione le reference, i puntatori e gli iteratori agli elementi non valgono più.

Gli elementi contigui

Gli elementi di un std::vector stanno uno dopo l’altro nella memoria, come in un array: &v[1] è &v[0] + 1. Nella Lezione 14 l’ordine dei cicli contava proprio per questo: la CPU legge più in fretta elementi vicini.

Un vettore di vettori non è contiguo:

std::vector<std::vector<double>> immagine;     // per ora vuoto
for (int i = 0; i < 28; i++) {
    std::vector<double> riga;                  // una riga nuova, con il suo blocco
    for (int j = 0; j < 28; j++) riga.push_back(0.0);
    immagine.push_back(riga);
}
immagine[14][14] = 1.0;

immagine contiene 28 std::vector<double>, e ognuno ha un suo blocco nell’heap, come le righe della matrice fatta con un array di puntatori nella Lezione 08: due righe consecutive non stanno una dopo l’altra in memoria.

Per questo la Matrix del Laboratorio 05, e le matrici di Eigen, tengono tutti gli elementi in un solo blocco, e calcolano a mano la posizione di un elemento dalla riga e dalla colonna.

Gli iteratori: begin() ed end()

Nella Lezione 16 std::sort(w, w + 5) riceveva il primo elemento e la posizione subito dopo l’ultimo. Per un contenitore li danno due metodi:

  • v.begin(): un iteratore che indica il primo elemento;
  • v.end(): un iteratore che indica la posizione subito dopo l’ultimo. Non indica un elemento: serve a sapere dove fermarsi.

Un iteratore si usa come un puntatore: *it è l’elemento indicato e it-> accede ai suoi membri, ++it passa all’elemento successivo, it != v.end() controlla se si è arrivati in fondo.

Per un std::vector un iteratore è in pratica un puntatore. In un contenitore che non è un array, come std::map, ++it trova l’elemento successivo anche se in memoria non è accanto: per questo molti algoritmi, che usano solo ++ e *, funzionano con ogni contenitore. std::sort no: usa anche it + k, che c’è solo per std::vector e gli array.

Un ciclo con gli iteratori

iteratori.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<double> v = {1.5, 2.5, 3.5};
    for (std::vector<double>::iterator it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << "\n";
    for (auto it = v.begin(); it != v.end(); ++it) {
        *it = 2 * *it;
    }
    std::cout << v[0] << " " << v[1] << " " << v[2] << "\n";
    return 0;
}
  • Riga 6: il tipo dell’iteratore di un std::vector<double> è std::vector<double>::iterator. Stampa 1.5 2.5 3.5.
  • Riga 10: con auto (Lezione 14) il tipo lo deduce il compilatore da v.begin(). Attraverso *it gli elementi si possono anche modificare: stampa 3 5 7.

Il for sugli elementi

Il for della Lezione 12, for (double x : v), è un ciclo con gli iteratori scritto in breve: va da v.begin() a v.end(). La variabile del ciclo può essere una copia o una reference:

riferimenti.cpp
#include <iostream>
#include <memory>
#include <vector>
#include "layers.hpp"     // quello della Lezione 16, copiato in LEZIONE_18

int main() {
    std::vector<double> v = {1.5, 2.5, 3.5};
    for (double x : v) x = 2 * x;
    for (double& x : v) x = 2 * x;
    for (const double& x : v) std::cout << x << " ";
    std::cout << "\n";

    std::vector<std::unique_ptr<DenseLayer>> rete;
    rete.push_back(std::make_unique<DenseLayer>(128, 784));
    rete.push_back(std::make_unique<DenseLayer>(10, 128));
    for (const auto& d : rete) std::cout << d->numero_pesi() << " ";
    std::cout << "\n";
    return 0;
}

Copia o reference

In riferimenti.cpp:

for (double x : v) x = 2 * x;                                      // riga 8
for (double& x : v) x = 2 * x;                                     // riga 9
for (const double& x : v) std::cout << x << " ";                   // riga 10
for (const auto& d : rete) std::cout << d->numero_pesi() << " ";   // riga 16
  • riga 8: x è una copia dell’elemento: il ciclo raddoppia la copia, e v non cambia;
  • riga 9: x è una reference all’elemento: il ciclo raddoppia gli elementi di v;
  • riga 10: una reference const: niente copia, e nessuna modifica. Stampa 3 5 7;
  • riga 16: auto al posto del tipo, che è std::unique_ptr<DenseLayer>; stampa i pesi dei due layer, 100352 e 1280.

Regola pratica. Una copia per i tipi piccoli, come int e double; const auto& per leggere oggetti più grandi, come stringhe e layer, e quelli che non si copiano, come std::unique_ptr; auto& per modificarli.

Provate: copia o reference

  1. In riferimenti.cpp, alla riga 9, togliete la &. Cosa stampa la prima riga?
    1.5 2.5 3.5: tutti e due i cicli raddoppiano una copia, e v resta com’era.
  2. Rimettete la & e, alla riga 16, scrivete for (auto d : rete). Compila?
    No: use of deleted function 'std::unique_ptr<_Tp, _Dp>::unique_ptr(const std::unique_ptr<_Tp, _Dp>&)'. Con auto d ogni elemento si copierebbe in d, e un std::unique_ptr non si copia (Lezione 17). Per questo nel framework il ciclo sui layer è for (auto& l : layers).

std::map: un valore per ogni chiave

std::map<K, V> (da <map>) tiene coppie chiave, di tipo K, e valore, di tipo V: un valore si cerca dalla sua chiave, invece che da un indice.

mappa.cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, double> config;
    config["learning_rate"] = 0.01;
    config["momentum"] = 0.9;
    std::cout << config["learning_rate"] << "\n";
    std::cout << config.size() << " chiavi\n";
    return 0;
}

Righe 7 e 8: config[chiave] è il valore della chiave, che si può leggere o assegnare; se la chiave non c’è, prima la crea, con il valore 0. Riga 9: la chiave c’è, e stampa 0.01; riga 10: 2 chiavi.

Provate: [] con una chiave assente

In mappa.cpp, alla riga 9, scrivete "learnig_rate", senza la seconda n, come per un errore di battitura. Cosa stampa?

0
3 chiavi

Nessun errore e nessun avviso: la lettura con [] ha creato la chiave learnig_rate, con il valore 0, e il programma continua con un learning rate nullo. Per leggere una chiave che potrebbe non esserci si usa find, nella slide seguente.

Cercare una chiave: find

cerca.cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, double> config = {{"momentum", 0.9}, {"learning_rate", 0.01}};
    auto it = config.find("learnig_rate");
    if (it == config.end()) {
        std::cout << "chiave assente\n";
    }
    it = config.find("momentum");
    std::cout << it->first << " = " << it->second << "\n";   // chiave e valore della coppia
    for (const auto& p : config) {
        std::cout << p.first << " = " << p.second << "\n";
    }
    std::cout << config.size() << " chiavi\n";
    return 0;
}
  • Riga 6: una mappa si riempie anche con un elenco di coppie fra graffe.
  • Righe 7 e 11: find restituisce un iteratore alla coppia con quella chiave, o config.end() se non c’è. Non crea niente: alla fine le chiavi sono ancora 2.

Gli elementi di una mappa

Gli elementi di una std::map<K, V> sono coppie, di tipo std::pair<const K, V>: first è la chiave, const perché non si può cambiare, e second è il valore. In cerca.cpp:

  • riga 12: it->first e it->second sono la chiave e il valore della coppia trovata, e stampa momentum = 0.9;

  • righe 13-15: il for scorre le coppie, con const auto& per non copiare le stringhe, e stampa

    learning_rate = 0.01
momentum = 0.9

    in ordine alfabetico delle chiavi, anche se nella riga 6 sono scritte nell’altro ordine.

Com’è fatta una std::map

Le chiavi sono sempre in ordine perché una std::map tiene le coppie in un albero binario di ricerca: a sinistra di ogni nodo stanno le chiavi minori, a destra le maggiori, come nell’esercizio facoltativo della Lezione 17. L’albero però è bilanciato: mentre le coppie si inseriscono si riorganizza, e la sua profondità resta dell’ordine di log₂ N anche se le chiavi arrivano già in ordine.

Per trovare una chiave fra un milione bastano quindi una ventina di confronti: log₂ 10⁶ ≈ 20. Per confronto, std::sort ordina N elementi con un numero di confronti dell’ordine di N log₂ N.

std::unordered_map, da <unordered_map>, non tiene le chiavi in ordine: da ogni chiave calcola un numero, il suo hash, che dice dove cercarla. Per trovare una chiave bastano così in media pochi passi, lo stesso numero con dieci chiavi o con un milione. Con la O grande dell’analisi, per \(N \to \infty\): \(O(1)\) in media, contro \(O(\log N)\) per std::map. Si usa come std::map, con [] e find, ed è più veloce anche a inserire: si sceglie quando l’ordine delle chiavi non serve.

Alcuni algoritmi di <algorithm>

algoritmi.cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {5, 0, 4, 1, 9, 2, 1, 3};
    std::sort(v.begin(), v.end());
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
    auto it = std::find(v.begin(), v.end(), 4);
    std::cout << it - v.begin() << "\n";
    std::cout << std::count(v.begin(), v.end(), 1)
              << "\n";
    std::cout << *std::max_element(v.begin(), v.end())
              << "\n";
    return 0;
}

Ognuno riceve l’intervallo da begin() a end():

  • std::sort (Lezione 16) ordina: 0 1 1 2 3 4 5 9;
  • std::find restituisce un iteratore al primo 4, o end(); per un vettore it - v.begin() è la posizione, 5;
  • std::count conta gli 1: 2;
  • std::max_element restituisce un iteratore al massimo, e * lo legge: 9.

Il criterio di confronto: le lambda

Per un criterio diverso da <, std::sort e std::max_element ricevono un terzo argomento: una funzione che restituisce true se a va prima di b, scritta sul posto come lambda: una funzione senza nome, con [], i parametri fra tonde e il corpo fra graffe.

lambda.cpp
#include <algorithm>
#include <cmath>
#include <iostream>
#include <vector>

int main() {
    std::vector<double> w = {0.42, -0.91, 0.05, 0.77};
    auto m = std::max_element(w.begin(), w.end(),
                              [](double a, double b) { return std::abs(a) < std::abs(b); });
    std::cout << "massimo in modulo: " << *m << "\n";    // -0.91
    std::sort(w.begin(), w.end(), [](double a, double b) { return a > b; });
    for (double x : w) std::cout << x << " ";          // 0.77 0.42 0.05 -0.91
    std::cout << "\n";
    return 0;
}

Provate: le lambda

  1. In lambda.cpp, alla riga 11, scrivete a < b al posto di a > b. Cosa stampa l’ultima riga?
    -0.91 0.05 0.42 0.77: con a < b la lambda è il confronto normale, e l’ordine è crescente, come senza lambda.
  2. Alla riga 11 fate ordinare i pesi per modulo crescente. Cosa stampa?
    Con return std::abs(a) < std::abs(b); stampa 0.05 0.42 0.77 -0.91.

Il tipo restituito da una lambda lo deduce il compilatore dal return. Fra le [] si possono elencare variabili locali della funzione in cui la lambda è scritta, per usarle nel suo corpo: la lambda le cattura. Qui, e nel framework, le [] restano vuote. std::count_if è come std::count, ma al posto del valore riceve una funzione, per esempio una lambda, che restituisce true per gli elementi da contare. Al posto del tipo dei parametri si può scrivere auto, [](auto a, auto b): il tipo lo deduce il compilatore, come in un template.

Esercizio: quante immagini per cifra

Scopo: contare con una std::map quante volte compare ogni cifra fra le prime 20 etichette di mnist_train.csv, e cercare una cifra con find. Qui la lettura con [], che crea la chiave con il valore 0, è proprio quello che serve.

  1. In esercizio_conteggio.cpp (slide seguente) completate il main, come descritto nei commenti.

  2. Compilate ed eseguite:

    cmake -B build && cmake --build build --target esercizio_conteggio && ./build/esercizio_conteggio

  3. In che ordine escono le cifre, e perché?

Conteggio: il file da completare

esercizio_conteggio.cpp
#include <iostream>
#include <map>
#include <vector>

int main() {
    // le prime 20 etichette di mnist_train.csv
    std::vector<int> etichette = {5, 0, 4, 1, 9, 2, 1, 3, 1, 4, 3, 5, 3, 6, 1, 7, 2, 8, 6, 9};
    std::map<int, int> conteggio;    // cifra -> quante volte compare
    // da completare:
    // - con un for sulle etichette, aumentate di 1 conteggio[e] per ogni etichetta e;
    // - con un for sugli elementi di conteggio, coppie std::pair con first = cifra
    //   e second = volte, stampate per ogni cifra "cifra: volte";
    // - con find, cercate la cifra 9 e, se c'e', stampate "il 9 compare ... volte";
    // - stampate quante cifre diverse ci sono, con size()
    return 0;
}

Compila così com’è e non stampa niente. Alla prima volta che compare una cifra, conteggio[e] crea la chiave con il valore 0: conteggio[e]++ la porta a 1.

Soluzione dell’esercizio

esercizio_conteggio.cpp
#include <iostream>
#include <map>
#include <vector>

int main() {
    // le prime 20 etichette di mnist_train.csv
    std::vector<int> etichette = {5, 0, 4, 1, 9, 2, 1, 3, 1, 4, 3, 5, 3, 6, 1, 7, 2, 8, 6, 9};
    std::map<int, int> conteggio;    // cifra -> quante volte compare
    for (int e : etichette) {
        conteggio[e]++;
    }
    for (const auto& p : conteggio) {
        std::cout << p.first << ": " << p.second << "\n";
    }
    auto it = conteggio.find(9);
    if (it != conteggio.end()) {
        std::cout << "il 9 compare " << it->second << " volte\n";
    }
    std::cout << conteggio.size() << " cifre diverse\n";
    return 0;
}

Soluzione: cosa stampa

0: 1
1: 4
2: 2
3: 3
4: 2
5: 2
6: 2
7: 1
8: 1
9: 2
il 9 compare 2 volte
10 cifre diverse
  • Le cifre escono in ordine crescente, perché la mappa tiene le chiavi in ordine.
  • Riga 10: la prima volta che compare una cifra, conteggio[e] crea la chiave con il valore 0, e ++ la porta a 1.
  • Riga 15: find(9) restituisce un iteratore alla coppia con chiave 9, e it->second è il suo conteggio.

Soluzione del secondo esercizio

esercizio_frequenze.cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <vector>

int main() {
    std::vector<int> etichette = {5, 0, 4, 1, 9, 2, 1, 3, 1, 4, 3, 5, 3, 6, 1, 7, 2, 8, 6, 9};
    std::map<int, int> conteggio;
    for (int e : etichette) {
        conteggio[e]++;
    }
    auto it = std::max_element(conteggio.begin(), conteggio.end(),
        [](const auto& a, const auto& b) { return a.second < b.second; });
    std::cout << "la cifra " << it->first << " compare " << it->second << " volte\n";
    int n = std::count_if(conteggio.begin(), conteggio.end(),
        [](const auto& p) { return p.second >= 3; });
    std::cout << n << " cifre compaiono almeno 3 volte\n";
    std::sort(etichette.begin(), etichette.end(), [](int a, int b) { return a > b; });
    for (int e : etichette) std::cout << e << " ";
    std::cout << "\n";
    return 0;
}

Soluzione: cosa stampa

la cifra 1 compare 4 volte
2 cifre compaiono almeno 3 volte
9 9 8 7 6 6 5 5 4 4 3 3 3 2 2 1 1 1 1 0
  • Righe 12-13: std::max_element confronta le coppie con la lambda, cioè per numero di volte, e restituisce un iteratore alla coppia con chiave 1 e valore 4.
  • Righe 15-16: std::count_if conta le coppie per cui la lambda restituisce true: le cifre 1 e 3.
  • Riga 18: la lambda a > b mette prima i numeri più grandi.
