  ntype vij(particleLJ P, pvector<ntype,3> L)
    {
      ntype ene;
      pvector<ntype,3> Dr;
     
      Dr = r - P.r;
      // MINIMUM IMAGE CONVENTION 
      Dr = Dr - mulcw(L,rint(divcw(Dr,L))); // Dr - L*rint(Dr/L)
      ntype rsq, rn = Dr.norm();
      rsq = rn*rn; 
      if (rsq < rc*rc) // interaction potential cut-off
        ene = 4.0*epsilon*(pow(sigma/rn,12.0)-pow(sigma/rn,6));
      else
        ene = 0.0;
      return ene;

    }
  • tra_move(), store(), restore(): one line each.
  • vij(): the minimum image of \(\mathbf{r}_i - \mathbf{r}_j\), then the Lennard-Jones potential within the cutoff.

sim: energies and PBC

project/sim.hpp

  // if opt=1 calculate energies only for i < j
  ntype calcenergyi(int i, int opt=0) 
    {
      int j;
      ntype enei=0.0;
      for (j=0; j < pars.Np; j++) // pars.Np is the total number of particles
        {
          if (opt==1 && i >= j)
            continue;
          if (i==j)
            continue;
          // the particle class must provide a method vij to calculate the interaction energy
          enei += parts[i].vij(parts[j], pars.L); 
          // pars.L is a vector with the sides of the box 
        }
      return enei;
    }
  
  ntype totenergy(void)
    {
      ntype ene=0.0;

      for (auto i=0; i < static_cast<int>(parts.size()); i++)
        {
          ene+=calcenergyi(i, 1);
        }
      return ene;
    }

  void pbc(int i) 
    {
      auto Dr = parts[i].r;
      Dr = mulcw(pars.L,rint(divcw(Dr,pars.L))); // L*rint(Dr/L)
      parts[i].r = parts[i].r - Dr;
    }

mcsim: a class derived from sim

  • mcsim<ntype, particle_type> is derived from sim<ntype, particle_type>: it inherits the particles, the parameters, the energies, the PBC, the snapshots, the initial configuration (using for the names of the base class, example N10).
  • It adds what the Monte Carlo needs:
    • the NTV ensemble (today): alpha() (trial move), acc() (acceptance), move_NTV(), calc_acceptance_and_adjust(), init_measures(), save_measures();
    • the NPT ensemble (Lab #8): move_box(), alpha_box(), acc_box(), store_all_pars(), restore_all_pars();
    • the main loop run(), which hides the empty run() of sim.
  • run() and move_box() are given; the other methods are skeletons.

run(): how it works

  • One MC step = pars.Np trial moves, each on a particle chosen at random (rng.ranf()*pars.Np, converted to int): on average each particle is moved once.
  • Every savemeasure steps save_measures(), every outstps steps the energy per particle on the screen (“total energy per particle” is the potential energy per particle, \(U/N_p\)), every save_mgl_snapshot steps a snapshot.
  • Every adjstps steps, but only for t < maxadjstps, calc_acceptance_and_adjust() changes the maximum displacement. After maxadjstps it stays fixed: with a maximum displacement that changes with the history of the run the chain does not satisfy detailed balance, so the measures are taken with a fixed one.

Hints: the trial move

  • rng is the random number generator of randnumgen.hpp (Lab #4), a global object: rng.ranf() returns a number uniform in \([0,1)\).
  • alpha(i): a displacement delr, a pvector<ntype,3> with components uniform in \([-\delta, \delta)\), \(\delta\) = pars.deltra: each one is pars.deltra*2.0*(rng.ranf()-0.5) (x, y, z in this order), or simply delr.random(2.0*pars.deltra) (Lab #4), which gives the same numbers. Then parts[i].tra_move(delr) and pbc(i).
  • move_NTV(i), the four steps of the comments:
    1. eno = calcenergyi(i): the energy of particle i with all the others (opt = 0, the default), before the move;
    2. parts[i].store();
    3. alpha(i);
    4. acc(i, eno).

Hints: the Metropolis criterion, soft spheres

  • acc(i, eno): only particle i has moved, so the change of the total energy is \(\Delta U\) = calcenergyi(i) \(-\) eno (below, delu).
  • Accept with probability \(\min\{1, e^{-\Delta U/T}\}\): draw xi = rng.ranf(), then reject if \(\Delta U > 0\) and \(\xi \ge e^{-\Delta U/T}\) (exp(-delu/pars.T)). For a rejected move, parts[i].restore() and tra_rej++ (the trial moves are counted in run(), tot_tra++).
  • Draw xi at every call, before the test. Drawing it only when \(\Delta U > 0\) (as in the comment) is also right, but uses the random numbers in another order: at step 200 you would get -3.03522, not -3.08162.
  • particleSS::vij(): as particleLJ::vij(), with only the repulsive term, \(v(r) = 4\epsilon(\sigma/r)^{12}\) for \(r < r_c\). To test it: particleSS<double> instead of particleLJ<double> in mcsim.cpp (or in a copy of it).

Hints: acceptance rate and measures

  • calc_acceptance_and_adjust(): the acceptance rate of the last adjstps steps, (tot_tra - tra_rej)/tot_tra, in floating point (the counters are integers: cast one of the two to double). Print it with deltra, so that the line is the one of the slides:

    std::cout << "rate tra: " << rate << " deltra=" << pars.deltra << "\n";

    then, if the rate is above 0.5, pars.deltra *= 1.1, otherwise pars.deltra /= 1.1; set tot_tra and tra_rej back to 0.

  • init_measures(): as in save_mgl_snapshot(), a std::fstream f; open energy.dat with std::ios::out|std::ios::trunc and close it: an old file is emptied.

  • save_measures(t): open energy.dat with std::ios::out|std::ios::app (append at the end), write t, a space, totenergy()/pars.Np and "\n", and close it.

Classic pitfalls

  • No restore() for a rejected move: the rejected moves stay, particles overlap, and total energy per particle is 7.10939e+08. The same if eno is computed after alpha(): then \(\Delta U = 0\) and every move is accepted (rate tra: 1).
  • The inequality reversed (reject if \(\xi < e^{-\Delta U/T}\)): rate tra: 0.95 and energies of order \(10^9\).
  • exp(-delu*pars.T) instead of exp(-delu/pars.T): a run at temperature \(1/T = 0.5\), \(U/N_p \simeq -4.6\) and acceptance rate about 0.3.
  • No tra_rej++ (rate tra: 1) or a division between integers in the rate (rate tra: 0): deltra grows, or shrinks, at every adjustment. The energy is still right, the adjustment is not.
  • No pbc() in alpha(): the energy is right (minimum image), but the particles leave the box: cnf-1000.mgl has coordinates up to 11.8, with \(L/2 \simeq 5.04\).
